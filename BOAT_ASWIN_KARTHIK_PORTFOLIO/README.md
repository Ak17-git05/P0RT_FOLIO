# BOAT — ASWIN KARTHIK.G // AI ENGINEERING LAB

An independent interactive portfolio project built around the BOAT concept:
a visual journey through an AI / ML engineer's work at the intersection of Computer Science and Medical Engineering.

## What is inside

- `index.html` — complete portfolio structure and resume-grounded content
- `styles.css` — visual system, responsive layout, motion, technical UI
- `app.js` — Three.js particle/network world, interactions and visual behavior
- `assets/` — reserved for future project-specific media

## Run locally

### Simplest
Open `index.html` in a modern browser.

Because the project loads Three.js from a public CDN, internet access is required for the WebGL module.

### Recommended
Use a local static server:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`

## Notes

This version intentionally avoids fabricated project metrics. The cervical cancer metrics shown are the metrics supplied in the resume. The heart-disease section shows evaluation dimensions without inventing numerical results.

The project is independent of any existing portfolio.
