# BOAT — ASWIN KARTHIK AI ENGINEERING LAB / AERO EDITION

A premium, formal, futuristic Frutiger-Aero inspired evolution of the BOAT portfolio. This is a **new project** and does not modify the original BOAT build.

## What changed
- Glass/aqua/sky/leaf visual system instead of the original dark-green-only palette.
- Stronger, filled primary buttons with clear hierarchy.
- Interactive Three.js "aero data organism" that reacts to pointer movement.
- Glass cursor droplet, elastic ring and click ripples.
- Subtle perspective/magnetic interactions on hero and project surfaces.
- Responsive and reduced-motion aware.
- Existing portfolio facts/content preserved; no new achievements or fabricated benchmarks were added.

## Run
This build loads Three.js and fonts from CDNs.

### Option A
Open `index.html` in a modern browser.

### Option B
From this folder run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Files
- `index.html` — portfolio structure
- `styles.css` — Aero visual system and responsive layout
- `app.js` — Three.js interaction, cursor, tilt, pipeline and transformation interactions
- `assets/favicon.svg` — favicon
- `manifest.webmanifest` — web app metadata

## Notes
The original `BOAT_ASWIN_KARTHIK_PORTFOLIO` folder remains untouched. This folder is the new Aero edition.
